# RAGTruth-600 Dataset Card

Source: [ParticleMedia/RAGTruth](https://github.com/ParticleMedia/RAGTruth), MIT licensed
(see `LICENSE-RAGTruth`). These are original public model responses and human annotations,
not answers generated by VerifiGen. Upstream source documents may have their own terms.

## Contents

- `selection.jsonl`: frozen response IDs, source IDs, task, original/local split and binary label.
- `samples.jsonl`: selected responses joined to their original source material and annotations.
- `manifest.json`: official file hashes, selection hash, quotas and source counts.

600 responses from 451 sources: QA, Summary and Data2txt each have 200 responses. Each task
has 30 clean + 30 hallucinated development responses from the official train split and
70 clean + 70 hallucinated evaluation responses from test. Source IDs never cross local splits.
The 50/50 balance is a controlled evaluation distribution, not real-world error prevalence.
Original responses come from Llama-2-7B/13B/70B, Mistral-7B-Instruct, GPT-3.5-Turbo and GPT-4;
Qwen3.5-Flash is VerifiGen's reviewing/repairing model, not the original corpus generator.
On this cohort, serialized original evidence averages 2,405 characters (maximum 10,689),
and original responses average 797 characters (maximum 1,965). Full evidence is retained;
short natural responses are not padded with synthetic text.

QA sources contain questions and retrieved passages (MS MARCO); Summary sources contain
news articles (CNN/DailyMail and recent news); Data2txt sources contain Yelp business records
and reviews. The official corpus contains 17,790 responses and 2,965 source records.

Only `quality=good` responses are selected. A response is hallucinated if at least one annotated
span has `implicit_true != true`. Implicitly true spans remain in the original annotations but do
not constitute a positive label. Labels are consumed by the evaluator, never the model adapter.
Original labels evaluate first judgments only; a rewritten answer needs a new independent review.

## Reproduction

```bash
python scripts/download_ragtruth.py --output runs/ragtruth-official
python scripts/build_ragtruth_eval.py \
  --responses runs/ragtruth-official/response.jsonl \
  --sources runs/ragtruth-official/source_info.jsonl
git diff --exit-code -- benchmarks/data/ragtruth-600
```

Git blob IDs and SHA-256 digests are pinned: an upstream update cannot silently change this cohort.
See [the evaluation protocol](../../../docs/ragtruth_evaluation.md) for metrics and limitations.
